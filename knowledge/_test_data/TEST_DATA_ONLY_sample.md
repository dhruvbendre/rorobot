# TEST_DATA_ONLY: Lantern Kite

This document is obviously fictional test data used only to exercise retrieval. It describes no real person. Never treat it as information about Dhruv Bendre.

## What the Lantern Kite is

The Lantern Kite is a fictional weather-balloon experiment invented for testing. It carries a paper lantern under a small kite and records wind speed with a pinwheel sensor made of bottle caps.

## What the Lantern Kite taught

The fictional lesson of the Lantern Kite is that bottle-cap pinwheels stall below three knots of wind, so the fictional team switched to a spinning cup anemometer for the second flight.

## Materials used

The fictional kite was built from bamboo, tissue paper, kitchen string and a recycled bicycle spoke.
