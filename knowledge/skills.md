# Skills

Dhruv Bendre's skills centre on Python, data analysis and building AI systems with large language models and agents.

## Languages

- Python: a versatile programming language Dhruv uses for software development, automation, data analysis, artificial intelligence and machine learning. It is his primary language.
- SQL: used to store, retrieve, manage and analyse data in relational databases.
- Web development (full stack): creating, building and maintaining websites and web applications with HTML, CSS, JavaScript and modern frameworks.

## AI and agent frameworks

- LangChain: a framework for building AI applications powered by large language models, integrating tools, data sources, memory and external APIs.
- LangGraph: a framework for stateful, multi-agent AI applications and complex LLM workflows using a graph-based architecture.
- Agno: a framework for building AI agents and multi-agent systems that use tools, memory, knowledge and external services to perform complex tasks.
- RAG (Retrieval-Augmented Generation): an AI technique that retrieves relevant information from external data sources so LLMs generate more accurate, context-aware responses. Used in the Get Set Learn hackathon assistant.
- Groq (Llama 3.3 70B) and Tavily Search: the model and web search behind the multi-agent research system.

## Data

- Pandas: a Python library for data manipulation, cleaning and analysis.
- Power BI: interactive dashboards built during internships at NullClass and My Equity School.
- Excel: campaign data organisation at SocioHub.

## Tools

- Streamlit: the web interface for SnapClass, the research system, the hackathon platform and MyChessBot.
- Supabase: database and backend for the hackathon platform.
- n8n: a no-code/low-code workflow automation platform used to connect apps, APIs, databases and AI tools.
- Computer vision: MediaPipe, CVZone, dlib and WebRTC for real-time hand-gesture and face recognition.
- Classical machine learning: SVM (SnapClass facial recognition) and Random Forest (sign language classifier).
- PyDub for voice authentication audio; BeautifulSoup for web scraping; Stockfish as a chess engine.
